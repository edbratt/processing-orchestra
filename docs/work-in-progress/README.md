# Work In Progress Docs

This folder holds planning, status, spec, handoff, and scratch-note documents that are still useful for ongoing work but should not crowd the repository root.

Contents currently include:
- browser input mode specs and implementation plans
- PDE converter specs, plans, remaining steps, and status
- handoff and scratch notes
- temporary follow-up and planning material

Guideline:
- keep stable user-facing/project-facing documentation in higher-level docs
- keep evolving implementation notes, plans, and status documents here

Historical note:
- some older notes may refer to pre-reorganization root-level docs such as `ARCHITECTURE.md`, `CUSTOMIZATION.md`, or `RUNTIME_OVERVIEW.md`
- the stable versions now live under `docs/`, for example `docs/architecture.md`, `docs/java-coding/customization-guide.md`, and `docs/java-coding/runtime-overview.md`
